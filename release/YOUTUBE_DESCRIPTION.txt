TITLE:
FastString: Ultra-Fast SIMD Native UTF-8 String Engine for Java 🚀

DESCRIPTION:
Demonstrating FastString, the zero-copy, SIMD-accelerated mutable UTF-8 string engine for Java. Powered by the FastSIMD vector engine, FastString accelerates pattern searching (indexOf), zero-copy substring slicing, and case conversions at up to 10x-50x faster than java.lang.String without GC allocation pressure.

TECHNICAL HIGHLIGHTS:
- FastSIMD Hardware Vector Engine: 32-byte parallel quote/pattern scanning (indexOf) via native AVX2 intrinsics.
- Zero-Copy UTF-8 Substring Slicing: Shared buffer views eliminate heap object allocations during string manipulation.
- In-Place Mutation: Mutable character manipulation for high-frequency logs and API request streams.
- Official JMH Suite: Standardized benchmark Uber-JAR executable via run-benchmark.bat.

RESULTS:
- Pattern Search: 10x-50x speedup over java.lang.String.indexOf()
- Substring Slicing: Zero-copy execution with 0 bytes GC heap allocation
- JMH Throughput: 800,000+ ops/sec in pattern matching benchmarks
